# 部署指南 — GitHub Pages

## 概述

本项目使用 Vite + React 构建，通过 `gh-pages` 包一键部署到 GitHub Pages。
npm install --save-dev gh-pages

**仓库地址**: `git@github.com:zzf-gitch/careercompassai.git`  
**线上地址**: `https://zzf-gitch.github.io/careercompassai/`

---

## 前置条件

- Node.js >= 18
- npm >= 9
- Git 已配置并关联远程仓库

---

## 首次部署

### 步骤 1：确认配置

确保以下文件配置正确：

#### [`vite.config.js`](../vite.config.js) — 构建基础路径

```js
base: './'  // 必须为相对路径，确保子路径部署正常工作
```

#### [`package.json`](../package.json) — 部署脚本

```json
"scripts": {
  "build": "vite build",
  "deploy": "npm run build && gh-pages -d dist"
}
```

#### [`src/router/index.jsx`](../src/router/index.jsx) — 路由模式

```js
import { createHashRouter } from 'react-router-dom'
// 必须使用 HashRouter（createHashRouter），而非 BrowserRouter
// URL 格式：https://.../#/Dashboard
// GitHub Pages 不支持服务端路由重写，HashRouter 是唯一可靠的方案
```

### 步骤 2：一键部署

```bash
npm run deploy
```

执行过程：

```
> react-test@0.0.0 deploy
> npm run build && gh-pages -d dist

✓ built in 218ms (51 modules)
已复制         1 个文件  (dist\index.html → dist\404.html)
Published
```

### 步骤 3：配置 GitHub Pages 设置

1. 打开仓库 → **Settings** → **Pages**
2. **Source** 选择 `Deploy from a branch`
3. **Branch** 选择 `gh-pages` → `/(root)` → 点击 **Save**

等待 1-2 分钟，访问 `https://zzf-gitch.github.io/careercompassai/` 即可看到部署的站点。

## 日常更新

项目有代码变更后，只需运行一条命令即可更新线上站点：

```bash
npm run deploy
```

该命令会依次执行：
1. `vite build` — 生产构建（输出到 `dist/` 目录）
2. `postbuild` — 复制 `index.html` 为 `404.html`
3. `gh-pages -d dist` — 将 `dist/` 推送到远程 `gh-pages` 分支

## 常见问题

### Q：部署后访问或刷新页面出现 404？

**原因**：GitHub Pages 是静态文件服务器，无法像 Nginx 那样将所有路由请求重写到 `index.html`。使用 `createBrowserRouter`（History 模式）时，刷新非首页路由会直接请求不存在的路径。

**解决**：本项目已改用 [`createHashRouter`](../src/router/index.jsx)（Hash 模式）。URL 格式变为 `https://.../#/Dashboard`，`#` 后的部分不会被发送到服务器，因此刷新永不 404。这是 GitHub Pages 部署 SPA 最可靠的方式。

### Q：`npm run deploy` 报权限错误？

**原因**：gh-pages 需要推送权限。  
**解决**：确认远程仓库地址正确且有写入权限：

```bash
git remote -v
# origin  git@github.com:zzf-gitch/careercompassai.git (fetch)
# origin  git@github.com:zzf-gitch/careercompassai.git (push)
```

### Q：如何部署到自定义域名？

1. 在仓库 Settings → Pages 中填写自定义域名
2. 或在 `dist/` 目录下添加 `CNAME` 文件：

```bash
echo "your-domain.com" > dist/CNAME
```

3. 然后运行 `npx gh-pages -d dist`
